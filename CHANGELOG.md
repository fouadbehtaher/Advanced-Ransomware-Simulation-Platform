# Changelog

All notable changes to the Advanced Ransomware Simulation Platform (ARSP) will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-01-01

### Added
- Initial repository scaffolding
- Core configuration and logging modules
- Simulation engine with scenario support

- Sandbox isolation environment
- System and file monitoring capabilities
- Behavioral analysis module
- Report generation (JSON, text, HTML formats)
- Command-line interface (CLI)
- Comprehensive test suite
- Documentation structure
- Security and ethical usage guidelines
- Example configuration files

- Isolated sandbox environment for safe execution

### Documentation
- Installation guide
